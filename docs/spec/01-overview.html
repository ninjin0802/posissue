1. 概要と用語

1.1 目的

OSS 開発者が、利用者からのフィードバックを GitHub Issue に集約できるようにします。利用者側は GitHub への登録なしに報告でき、開発者側は projectKey を渡すだけで導入できます。

1.2 利用形態

形態説明
公式ホスト（既定）運営する公開サーバーを使う。作者は GitHub App をインストールし、発行された projectKey を設定するだけ。
セルフホスト作者が @posissue/server を使い、自分の Cloudflare アカウントにデプロイする。

1.3 用語

用語意味
作者 (Maintainer)ウィジェットを導入する OSS の開発者。
報告者 (Reporter)ウィジェットからフィードバックを送る人。GitHub アカウント不要。
プロジェクト1つのリポジトリと1つの projectKey の組。
projectKeypk_ で始まる公開キー。秘密ではない（ブラウザに置かれる）。
レポート (Report)報告者が送る1件の内容。Issue 1件に対応する。
種別 (kind)bug / feature / other。

1.4 v1 の基本方針

  • Issue は必ずウィジェット経由で作られ、via-widget ラベルが付く。
  • 報告者への返信機能は持たない。個人情報（メール等）は収集しない。
  • スパム対策は最初から必須機能として組み込む（7章）。
