2. アーキテクチャ

2.1 全体構成

[Web サイト] <script> / npm init()  ─┐
[アプリ]     WebView でフォーム URL    ─┼─▶ GET /r/:key（フォームページ, Turnstile）
[独自 UI]    API 直接                 ─┘          │ POST /api/report
                                                 ▼
                                   Cloudflare Worker（@posissue/server）
                                     ├ Turnstile 検証
                                     ├ Rate Limiting バインディング
                                     ├ D1（projects）
                                     └ GitHub App 認証 ─▶ GitHub REST API（Issue 作成）

2.2 技術スタック

役割採用
実行環境Cloudflare Workers（1 Worker に API・フォーム・ウィジェット配信を集約）
保存D1（プロジェクト設定）
投稿数制限Workers Rate Limiting バインディング
ボット対策Cloudflare Turnstile
言語TypeScript（全パッケージ）
GitHub 連携GitHub App（Issues: Read & Write、Metadata: Read のみ）

2.3 リポジトリ構成

packages/
  core/     @posissue/core    共通の型・バリデーション・Issue 本文の組み立て
  server/   @posissue/server  createHandler()（Workers 用ハンドラ）
  widget/   posissue          init() とブラウザ用 widget.js
apps/
  hosted/   公式ホスト（server を設定して使うだけ）
docs/spec/  本仕様書（SSOT）

2.4 依存の向き

widget → core、server → core、hosted → server。core は実行環境に依存しない（DOM も Workers API も使わない）。
