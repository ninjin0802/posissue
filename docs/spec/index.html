0. はじめに

PosIssue は、サイトやアプリにウィジェットを置くだけで、GitHub アカウントを持たない人でも OSS リポジトリへバグ報告・要望を Issue として送れるようにするフレームワークです。

この仕様書は唯一の正（SSOT）です。実装・ドキュメント・テストが食い違った場合は本仕様書に合わせ、仕様を変えるときは先に本仕様書を更新します。

この仕様書の読み方

  • 章の一覧は左のメニュー（nav.js で一元管理）にあります。
  • 「MUST」は必須、「SHOULD」は推奨、「MAY」は任意を表します。
  • 数値（制限値など）は初期値です。変更は本仕様書の該当章を更新して行います。
