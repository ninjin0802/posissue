8. ウィジェットとアプリ組み込み

8.1 Web ウィジェット

  • 画面の隅に固定ボタンを1つ置く。押すと /r/:key を iframe（モーダル）で開く。
  • Shadow DOM を使い、導入先サイトの CSS と干渉しない。
  • 自動で集める情報：page（URL。クエリとハッシュは除く）、userAgent、language、viewport。これに設定の meta を加える。
  • iframe との通信は postMessage。iframe からは posissue:done（送信完了）、posissue:close を送る。送信元 Origin を検証する。
  • Esc で閉じる。ボタンには aria-label を付ける。閉じたらボタンにフォーカスを戻す。

8.2 フォームページ

  • 入力：種別（カード型の選択）、タイトル、フォームの型（3.2）の各項目、Turnstile。種別を切り替えると項目も切り替わる。種別が1つなら選択は出さない。ハニーポットは画面外に置き、tabindex=-1 と aria-hidden を付ける。
  • 送信成功時は Issue 番号を表示する（リンクは任意）。
  • 日本語・英語に対応する。最初の言語は lang パラメータ、なければ navigator.language で決める。右上の「日本語 / English」で切り替えられ、切り替えても入力途中の内容は消えない。項目のラベルは型の LocalText から、エラーメッセージもその言語で出す。
  • JS バンドルなしの素の HTML と少しのインライン JS で作る。項目は型から textContent で組み立て、HTML を差し込まない。
  • 見た目：カード型の落ち着いたデザイン。ライト/ダーク自動切替、フォーカスリング、必須マーク、文字数カウンター、送信中スピナー、送信完了画面（Issue 番号へのリンク付き）。prefers-reduced-motion を尊重する。

8.3 アプリ組み込み

アプリは次の URL を WebView か外部ブラウザで開く。

{endpoint}/r/pk_xxx?app_version=1.2.0&os=ios&os_version=18.1

WebView の場合、送信完了を知るには posissue:done を window.parent に加えて、ページ遷移なしで window.ReactNativeWebView 等があればそこにも送る（MAY）。v1 ではネイティブ SDK を提供しない。

8.4 導入先サイトの CSP

厳しい CSP のサイトでは script-src {endpoint} と frame-src {endpoint} を許可してもらう必要がある。README に明記する。
