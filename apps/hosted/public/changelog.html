リリースノート

PosIssue の変更履歴です。各版の詳細は GitHub Releases にもあります。

v1.3.0 2026-11-17

新機能

  • サイトを日本語 / 英語に対応しました。トップページと管理画面は、ナビの切り替えかブラウザの言語で表示が変わります。プライバシーポリシー・利用規約・リリースノートの英語版（/en/）も用意しました。
  • トップページに作った人のプロフィールを載せました。

改善

  • 管理画面を「左に一覧、右に詳細」の形に作り直しました。リポジトリがいくつあっても、選んだ 1 つだけを表示します。一覧は承認待ちの多い順に並び、検索・絞り込み・矢印キーでの移動ができます。
  • 詳細に「Issue を見る」リンクを追加しました。
  • アイコンを新しいねこ（1 色のシルエットにスリット目）に変えました。OGP の画像も更新しています。
  • ヘッダーの「管理画面」と「GitHub」をアイコンにしました。
  • README を全面的に書き直し、英語版 README.en.md を追加しました。

修正

  • 古いアイコンがブラウザに残って表示される問題を直しました。
  • スマホでフッターのリンクが不自然に折り返す問題を直しました。

開発

  • サーバーの流れ（報告・スパム対策・承認・設定・OAuth・言語）の自動テストを追加しました（27 件）。

v1.2.0 2026-11-17

新機能

  • 承認モード：届いた報告を、作者が確認してから Issue にできるようになりました。公開リポジトリでは初期設定でオン、非公開リポジトリではすぐに起票します。管理画面の「設定」で切り替えられます。
  • 承認待ちの報告は管理画面で 1 件ずつ「起票する」「捨てる」を選べます。14 日で自動的に消えます。
  • 管理画面を /admin にまとめ、トップページから開けるようにしました（/keys も引き続き使えます）。

改善

  • 管理画面のデザインを作り直しました（リポジトリごとのタブ、承認待ちの件数表示、設定の切り替え）。
  • 作者向けの操作に専用の回数制限を設け、承認待ちをまとめて処理できるようにしました。

その他

  • プライバシーポリシーに、承認待ちの報告を最大 14 日保存することを追記しました。

v1.1.0 2026-11-17

新機能

  • 管理画面から、リポジトリごとに 埋め込みを許すサイト（最大 10）と 1 日の上限（1〜1000 件）を変えられるようになりました。

セキュリティ

  • 設定を変えられるのを、そのリポジトリの管理者（admin / maintain）だけにしました。
  • 設定の変更に使う署名にインストール ID を含め、有効期限を 15 分にしました。

v1.0.0 2026-11-17

最初の公開版です。

主な機能

  • サイトに <script> を 1 行置くだけ、アプリなら URL を WebView で開くだけで、GitHub アカウントのない人も Issue を送れるウィジェット。
  • フォームは型で決まる：FormTemplate を渡すと、画面・入力チェック・Issue 本文の形がそろって決まります。
  • 美しい送信フォーム（ライト / ダーク自動切替、日本語 / English 切り替え）。
  • スパム対策：Cloudflare Turnstile、ハニーポット、送信速度、URL の数、IP ごと・1 日ごとの制限、重複検出、@メンションと #番号の無効化。
  • GitHub App によるインストールと、キーの確認画面、CLI（npx github:ninjin0802/posissue keys）。
  • AI 向けの導入手順 /llms.txt と、開発ルール AGENTS.md。
  • 公式ホスト https://posissue.2nj.lol （Cloudflare Workers）、OGP、プライバシーポリシー、利用規約。

セキュリティ

  • 公開前のセキュリティ監査で見つかった問題を修正しました（セットアップ画面からの非公開リポジトリ名の漏えい、ログイン CSRF、URL 数の数え漏れ、Turnstile の hostname 確認、本文サイズの上限、CSP など）。
