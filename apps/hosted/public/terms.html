利用規約

制定日：2026年11月17日 ／ 運営：ninjin0802（個人）

この利用規約（以下「本規約」）は、PosIssue（以下「本サービス」）を利用するすべての方（ウィジェットを導入する方と、報告を送る方）に適用されます。本サービスを利用した時点で、本規約に同意したものとみなします。

1. サービスの内容

本サービスは、ウェブサイトやアプリに置いたウィジェットから送られた報告を、導入した方の GitHub リポジトリに Issue として作成するものです。本サービスは無料で、個人が運営しています。ソースコードは MIT ライセンスで公開しています。

2. 導入する方の責任

  • 自分が管理する、または管理を許されたリポジトリにだけ導入してください。
  • 報告者に対して、送信内容とページ・ブラウザの情報が Issue として掲載されることを、必要に応じて案内してください。
  • 作成された Issue の管理（公開・編集・削除）は、導入した方が行ってください。
  • GitHub の利用規約を守ってください。

3. 禁止事項

  • スパム、広告、迷惑な内容を大量に送ること
  • 他人を誹謗中傷する内容、違法な内容、他人の権利を侵害する内容を送ること
  • 他人の個人情報を送ること
  • ボット対策や投稿数の制限を回避しようとすること
  • 本サービスや GitHub、Cloudflare に過度な負荷をかけること
  • 本サービスの脆弱性を悪用すること（見つけた場合は、公開せずにご連絡ください）
  • その他、運営者が不適切と判断すること

禁止事項に当たる利用を見つけた場合、運営者は予告なく、該当するキーの停止や送信の拒否を行うことがあります。

4. 免責

  • 本サービスは「現状のまま」提供します。動作の継続、正確さ、特定の目的への適合を保証しません。
  • 本サービスの停止、遅延、データの消失、送られた報告の内容などによって生じた損害について、運営者は、運営者に故意または重大な過失がある場合を除き、責任を負いません。
  • 送られた報告の内容の責任は、その報告を送った方にあります。

5. サービスの変更・終了

運営者は、予告なく本サービスの内容を変更し、または提供を終了することがあります。終了する場合は、できるだけ事前にこのページやリポジトリでお知らせします。終了後も、セルフホスト（自分の環境で動かすこと）でお使いいただけます。

6. 規約の変更

本規約は必要に応じて変更することがあります。変更後に本サービスを利用した場合、変更後の規約に同意したものとみなします。

7. 準拠法

本規約は日本法に準拠します。

8. お問い合わせ

GitHub の Issue からご連絡ください。プライバシーについてはプライバシーポリシーもご覧ください。
