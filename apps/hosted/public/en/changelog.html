Changelog

Release history of PosIssue. Details are also on GitHub Releases.

v1.2.0 2026-11-17

New

  • Approval mode: review reports before they become issues. On by default for public repositories, immediate for private ones. Switch it in the dashboard settings.
  • Publish or discard pending reports one by one in the dashboard. They are deleted automatically after 14 days.
  • The dashboard now lives at /admin and is linked from the home page (/keys still works).

Improvements

  • Redesigned dashboard (tabs per repository, pending counts, settings toggles).
  • A separate rate limit for maintainer actions so you can review many reports at once.

Other

  • The privacy policy now explains that pending reports are stored for up to 14 days.

v1.1.0 2026-11-17

New

  • Change allowed sites (up to 10) and the daily limit (1–1000) per repository from the dashboard.

Security

  • Only repository admins (admin / maintain) can change settings.
  • Settings tokens now include the installation ID and expire after 15 minutes.

v1.0.0 2026-11-17

The first public release.

Highlights

  • A widget that lets anyone without a GitHub account send issues: one <script> line on a website, or a URL opened in an app WebView.
  • Typed forms: one FormTemplate defines the UI, validation and issue body.
  • A beautiful form (automatic light/dark, Japanese/English switch).
  • Spam protection: Cloudflare Turnstile, honeypot, timing, link count, per-IP and daily limits, duplicate detection, neutralized @mentions and #refs.
  • GitHub App installation, a key page and a CLI (npx github:ninjin0802/posissue keys).
  • /llms.txt for AI agents and AGENTS.md for contributors.
  • Hosted at https://posissue.2nj.lol (Cloudflare Workers), OGP, privacy policy and terms.

Security

  • Fixed issues found in a pre-release security audit (private repository names leaking from the setup page, login CSRF, link counting, Turnstile hostname check, request size limit, CSP, and more).
