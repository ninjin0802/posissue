6. GitHub App 連携

6.1 App の設定

項目値
権限Issues: Read & write / Metadata: Read-only（これ以外は付けない）
Setup URL{endpoint}/setup（Redirect on update を有効）
Webhook URL{endpoint}/webhook
購読イベントInstallation、Installation repositories

6.2 認証

  1. App の秘密鍵（PKCS#8 に変換したもの）で RS256 の JWT を作る。iat は 60 秒前、exp は 9 分後。署名は Web Crypto を使う。
  2. POST /app/installations/{id}/access_tokens でインストールトークンを得る。
  3. トークンは有効期限の 5 分前まで Worker のメモリにキャッシュしてよい（MAY）。
GitHub が配る鍵は PKCS#1（BEGIN RSA PRIVATE KEY）。登録前に openssl pkcs8 -topk8 -nocrypt -in app.pem -out app.pk8.pem で変換する。

6.3 Issue の形式
