PosIssue（以下「本サービス」）は、ウェブサイトやアプリに置いたウィジェットから、GitHub アカウントがなくても GitHub の Issue を送れるようにするサービスです。本サービスが扱う情報と、その使い方を説明します。

1. 報告する方（報告者）について

フォームから送信すると、次の情報が導入先のリポジトリの GitHub Issue として掲載されます。公開リポジトリの場合、誰でも閲覧できる状態になります。

導入先が承認モードを使っている場合（公開リポジトリでは初期設定で有効）、送信した内容はすぐには掲載されず、リポジトリの管理者が確認して「起票」を選んだときに掲載されます。それまでの間、次の情報を本サービスに最大 14 日間保存し、管理者だけが閲覧できます。管理者が「捨てる」を選ぶか、14 日が過ぎると削除します。

情報内容
入力した内容種別、タイトル、フォームの各項目
ページの URLウィジェットを開いたページの URL（クエリ文字列とハッシュは除く）
ブラウザの情報ユーザーエージェント、言語設定、画面の大きさ
アプリが付ける情報導入先のアプリが付けた情報（アプリのバージョン、OS など）

本サービスは、報告者の IP アドレス・氏名・メールアドレス・GitHub アカウントを収集・保存しません。ただし次の処理のために、IP アドレスを一時的に使います。

  • ボット対策：Cloudflare Turnstile による確認（Cloudflare 社が処理します）
  • 連続投稿の制限：短時間の回数の数え上げ（保存はしません）
  • 重複投稿の検出：送信内容から作った値（ハッシュ）を 24 時間だけ保存します。内容そのものは保存しません

個人を特定できる情報や、見られて困る情報は入力しないでください。掲載後の Issue の編集・削除は、そのリポジトリの管理者が行います。削除を希望する場合は、まずそのリポジトリの管理者にご連絡ください。

2. 導入する方（作者）について

GitHub App のインストール、キーの確認画面（/keys）、CLI を使うと、本サービスは次の情報を扱います。

  • GitHub App のインストール ID と、そのインストールで選ばれたリポジトリ名（キーとの対応を保存します）
  • GitHub でのログイン時に発行される一時的な認可情報（あなたがアクセスできるリポジトリを確認するためだけに使い、保存しません）

本サービスが GitHub に求める権限は、リポジトリの Issue の読み書きと、メタデータの読み取りだけです。ソースコードは読みません。

3. 利用する外部サービス

  • Cloudflare（Workers・D1・Turnstile）：本サービスの実行、データの保存、ボット対策
  • GitHub：Issue の作成、App の認証、作者の確認

これらの事業者は、それぞれのプライバシーポリシーに従って情報を扱います。

4. Cookie

キーの確認画面のログイン処理で、不正なログインを防ぐための Cookie（pi_state）を最大 10 分間だけ使います。広告やアクセス解析のための Cookie は使いません。Cloudflare Turnstile がボット対策のために独自の仕組みを使うことがあります。

5. 第三者への提供

法令に基づく場合を除き、上記以外の目的で第三者に提供しません。報告の内容は、報告者が送信先として選んだリポジトリに掲載されます。

6. 保存期間

  • プロジェクトの情報（リポジトリ名とキー）：App がアンインストールされたあとも、停止状態として残ります。削除を希望する場合はご連絡ください
  • 承認待ちの報告（承認モードのとき）：起票・破棄されるまで、最長 14 日
  • 重複検出用のハッシュ：24 時間
  • 日ごとの送信件数：集計のために日付とキーごとの件数を保存します

7. お問い合わせ

本ポリシーや本サービスの情報の扱いについては、GitHub の Issue からご連絡ください。公開の場に書きにくい内容は、その旨を Issue に書いていただければ、連絡方法をご案内します。

8. 改定

本ポリシーは、必要に応じて改定することがあります。重要な変更は、このページでお知らせします。
