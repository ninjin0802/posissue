Privacy Policy

Effective: November 17, 2026 / Updated: November 17, 2026 (approval mode) / Operator: ninjin0802 (individual)

PosIssue (the “Service”) lets anyone send GitHub issues from a widget placed on a website or app, without a GitHub account. This page explains what information the Service handles and how. The Japanese version is authoritative; this is a translation.

1. People who send reports (reporters)

When you submit the form, the following information is posted as a GitHub issue in the destination repository. For public repositories, anyone can see it.

InformationDetails
What you enterType, title and the form fields
Page URLThe URL of the page where the widget was opened (without query string and hash)
Browser informationUser agent, language setting and viewport size
App informationInformation added by the app (app version, OS, etc.)

If the destination uses approval mode (on by default for public repositories), your report is not posted immediately. It is posted only when a repository admin reviews it and chooses “Publish”. Until then, the information above is stored by the Service for up to 14 days and visible only to repository admins. It is deleted when an admin chooses “Discard” or after 14 days.

The Service does not collect or store your IP address, name, email address or GitHub account. Your IP address is used only temporarily for:

  • Bot protection with Cloudflare Turnstile (processed by Cloudflare)
  • Rate limiting (counting requests over a short time; not stored)
  • Duplicate detection (a hash of the content is kept for 24 hours; the content itself is not stored)

Please do not enter personal or sensitive information. Editing or deleting a posted issue is up to the repository’s maintainers; please contact them first.

2. People who install the widget (maintainers)

When you install the GitHub App or use the dashboard (/admin) or the CLI, the Service handles:

  • The GitHub App installation ID and the selected repository names (stored with the project key)
  • A temporary authorization issued when you sign in with GitHub (used only to check which repositories you can access; not stored)

The Service asks GitHub only for read/write access to issues and read access to metadata. It does not read your source code.

3. Third-party services

  • Cloudflare (Workers, D1, Turnstile): running the Service, storing data, bot protection
  • GitHub: creating issues, App authentication, verifying maintainers

These companies handle information under their own privacy policies.

4. Cookies

The dashboard sign-in uses a cookie (pi_state) for up to 10 minutes to prevent forged sign-ins, and the site remembers your language choice in a cookie (pi_lang). No advertising or analytics cookies are used. Cloudflare Turnstile may use its own mechanisms for bot protection.

5. Sharing with third parties

Except as required by law, information is not shared for any other purpose. Reports are posted to the repository the reporter sent them to.

6. Retention

  • Project information (repository name and key): kept in a disabled state after the App is uninstalled. Contact us to have it deleted.
  • Pending reports (approval mode): until published or discarded, up to 14 days
  • Duplicate-detection hashes: 24 hours
  • Daily counts: the number of reports per key and day

7. Contact

Please contact us via GitHub Issues. If the matter is not suitable for a public issue, say so in the issue and we will tell you how to reach us.

8. Changes

This policy may be updated as needed. Important changes will be announced on this page.
