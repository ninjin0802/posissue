9. 運用・制限・費用

9.1 デプロイ

  1. GitHub App を作り（6.1）、鍵を PKCS#8 に変換する。
  2. Turnstile のサイトを作る。
  3. wrangler d1 create → マイグレーション適用。
  4. wrangler secret put で Env の秘密を登録。
  5. wrangler deploy。公式ホストは posissue.2nj.lol（カスタムドメイン）。
  6. PosIssue 自身のリポジトリに App を入れ、発行されたキーを DEMO_KEY に設定する（ホームページのデモ用）。

9.2 既定の制限値

項目既定
IP ごと1 分に 2 件（wrangler の ratelimits 設定）
プロジェクトごと1 日 50 件
最短入力時間3 秒
URL 上限2 個
タイトル / 本文100 / 5000 文字
重複判定期間24 時間

9.3 費用の目安

Workers・D1・Turnstile はいずれも無料枠から始められる。利用量が増えた時点で有料プランを検討する。

9.4 ログ

拒否理由（エラーコード）とプロジェクトキーのみを console.log に出す。本文・IP は出さない。
